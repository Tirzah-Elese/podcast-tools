# Education Unraveled: Podcast Tools

Interactive reflection tools from ExelAcademy to go with our podcast, Education Unraveled. Each tool is a single web page that works in any browser, with nothing to install.

## Tools

| Tool | Folder | What it does |
| --- | --- | --- |
| My Values Hand | [`values-hand/`](values-hand/) | Write five values on the fingers of a hand, then reflect on where each came from, why it still matters, how deeply it is held, and how it shapes your days. |

## How it works

- Answers are saved only in the visitor's own browser. Nothing is sent anywhere.
- Visitors can copy their reflection as text to keep in their notes or email to themselves.

## Adding a new tool

Create a new folder with an `index.html` inside it, then add a card for it to the home page (`index.html`) and a row to the table above.
